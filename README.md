# Chinook SQL Analytics Project

## Project Overview

This project explores the Chinook music database using **SQLite, SQL, Python, and Google Colab**. The goal is to practice relational database queries, analyze music sales and customer purchasing patterns, and visualize insights from the data.

## Tools and Technologies

- **SQLite** – Relational database management
- **SQL** – Data retrieval, joins, filtering, aggregation, and analysis
- **Python** – Executing SQL queries and processing results
- **Pandas** – Organizing query results into DataFrames
- **Matplotlib** – Data visualization
- **Google Colab** – Interactive notebook environment

## SQL Skills Demonstrated

- Filtering and sorting records with `WHERE` and `ORDER BY`
- Combining tables using `JOIN`
- Aggregating data with `COUNT`, `SUM`, and `AVG`
- Grouping results with `GROUP BY`
- Conditional logic using `CASE`
- Common Table Expressions (CTEs)
- Handling duplicate values and case-insensitive comparisons
- Analyzing relationships across multiple tables

## Project Analyses

The notebook explores several questions, including:

- Which music genres generate the most sales?
- Which artists and albums perform best?
- How does revenue vary by country?
- What are the distributions of song lengths?
- How can SQL queries be structured and simplified using CTEs?

## Data Visualization

SQL query results are used to create visualizations, including:

- Music genre sales comparisons
- Revenue by country
- Artist sales rankings
- Song length distributions, including histograms and box plots

## Dataset

The project uses the sample **Chinook database**, which contains information about artists, albums, tracks, genres, customers, invoices, and invoice line items.

Source: [SQLite Tutorial – Chinook Sample Database](https://www.sqlitetutorial.net/sqlite-sample-database/)

## Running the Project

1. Open `SQL_3_Chinook_project.ipynb` in Google Colab.
2. Run the notebook cells in order.
3. The notebook downloads and extracts the Chinook database.
4. Explore the SQL queries, results, and visualizations.

## Conclusion

This project demonstrates practical SQL skills for exploring relational data, combining information across tables, answering analytical questions, and communicating results through data visualizations. It also provides a foundation for more advanced data analytics and data science projects.
